## Set up in three steps

<Steps>
  <Step title="Create a free account">
    Sign up at [app.adscrawl.net/register](https://app.adscrawl.net/register/). The Free plan includes 500 credits and one API key — no credit card required.
  </Step>
  <Step title="Copy your API key">
    Open the [dashboard](https://app.adscrawl.net/dashboard/), find your API key, and store it in an environment variable or secret manager. Never put your key in client-side code.
  </Step>
  <Step title="Make your first request">
    Send your API key in the `x-api-key` header and POST a URL to `/html`. You'll receive rendered HTML, Markdown, or structured article JSON back in the response body.

    ```bash
    curl --fail-with-body -sS -X POST "https://api.adscrawl.net/html" \
      -H "content-type: application/json" \
      -H "x-api-key: $ADSCRAWL_API_KEY" \
      -d '{
        "url": "https://example.com/article",
        "contentMode": "markdown",
        "waitUntil": "domcontentloaded"
      }'
    ```
  </Step>
</Steps>
