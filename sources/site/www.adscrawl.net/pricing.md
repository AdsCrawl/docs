Is there a free plan?

Yes. The Free plan includes a one-time 500-credit grant, two concurrent browsers, and one API key, so you can try screenshots, HTML extraction, and short CDP sessions.

Do credits renew every month?

Credits renew monthly on paid plans: 3,000 on Hobby, 100,000 on Starter, and 500,000 on Pro. The Free plan's 500 credits are a one-time grant.

Which plan is right for me?

Start with Free to evaluate the APIs. Choose Hobby for light personal automation, Starter for a small production team, or Pro for high-volume workflows. Compare credits, browser concurrency, profiles, and API keys before you decide.

Can I run a Cloud Browser on the Free plan?

You can save one Cloud Browser profile on Free, but you'll need a paid plan to launch it. Concurrent run limits for paid plans are set on your account.

What's the difference between browser concurrency and Cloud Browser profiles?

Browser concurrency is how many browsers you can run at once. Your profile allowance is how many Cloud Browser environments you can save. The two limits are separate.

How many API keys are included?

Free includes one API key; Hobby includes three; Starter includes 10; and Pro includes 30. Keep your keys on the server and out of browser-side code.

Are these prices monthly?

Yes. Hobby, Starter, and Pro cost $9, $49, and $199 per month in USD. Free costs $0 and includes a one-time credit grant. Review the final price in the dashboard before you check out.

Where can I see my plan and remaining credits?

Sign in to the AdsCrawl dashboard, then open Billing & Usage to see your plan, credit balance, and account limits.

What if I need more capacity?

Compare higher-tier plans in the dashboard. Before you upgrade, review the credits, browser concurrency, Cloud Browser profiles, API key limit, and final price shown at checkout.

How do I make my first API request?

Create an account, copy your API key from the dashboard, and send it in the x-api-key header. Then run an HTML, Scrape, Screenshots, or CDP example from the docs.
