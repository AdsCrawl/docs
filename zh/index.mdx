AdsCrawl 为开发者提供浏览器自动化 API。你可以发送一次请求获取网页渲染结果，也可以连接远程浏览器，完成跨页面或需要登录的操作。本指南涵盖从第一次 `curl` 请求到生产环境 Playwright 会话所需的身份验证、端点和示例。

## 三步发送第一条请求

<Steps>
  <Step title="创建免费账户">
    在[注册页](https://app.adscrawl.net/register/)创建账户。免费套餐包含 500 积分和一个 API 密钥，无需信用卡。
  </Step>
  <Step title="复制 API 密钥">
    在[控制台](https://app.adscrawl.net/dashboard/)复制密钥，保存到服务器环境变量或密钥管理器中。不要把密钥放进客户端代码。
  </Step>
  <Step title="发起请求">
    通过 `x-api-key` 请求头传递密钥，向 `/html` 提交目标 URL。下面的示例请求文章的 Markdown：

    ```bash
    curl --fail-with-body -sS -X POST "https://api.adscrawl.net/html" \
      -H "content-type: application/json" \
      -H "x-api-key: $ADSCRAWL_API_KEY" \
      -d '{"url":"https://example.com/article","contentMode":"markdown","waitUntil":"domcontentloaded"}'
    ```
  </Step>
</Steps>
