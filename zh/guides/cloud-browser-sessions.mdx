所有请求使用 `https://api.adscrawl.net`，并在 `x-api-key` 请求头中提供有效的账号 API Key。仅提供控制台 Cookie 或会话 JWT 会返回 HTTP 401。运行示例前设置 `ADSCRAWL_API_KEY`；操作单个配置时，将 `BROWSER_ID` 设为创建或列表接口返回的 UUID。

浏览器设置保存一次，后续使用同一配置 ID。创建不启动浏览器，停止保留已保存数据。

## 创建、启动并确认停止

需要 bash、curl 和 jq。示例使用 US 托管代理地区，也可改为在 browserSettings 保存自定义代理。以所有者身份登录后打开 runtime.connectUrl，使用结束后执行停止步骤。

```bash
# Requires bash, curl and jq. Set ADSCRAWL_API_KEY first.
set -euo pipefail
: "${ADSCRAWL_API_KEY:?Set ADSCRAWL_API_KEY first}"

# 1. Save a profile. Choose a managed region or save your own proxy.
created=$(curl --fail-with-body -sS --max-time 30 \
  "https://api.adscrawl.net/cloud-browsers" \
  -H "x-api-key: $ADSCRAWL_API_KEY" \
  -H "content-type: application/json" \
  --data '{"remark":"daily reports","browserSettings":{"countryCode":"US","viewport":{"width":1440,"height":900}}}')
BROWSER_ID=$(printf '%s' "$created" | jq -er '.id')
printf 'Saved profile: %s\n' "$BROWSER_ID"

# 2. Start with the saved settings. Keep the ID if this request times out.
if ! curl --fail-with-body -sS --max-time 200 \
  "https://api.adscrawl.net/cloud-browsers/$BROWSER_ID/start" \
  -H "x-api-key: $ADSCRAWL_API_KEY" \
  -H "content-type: application/json" --data '{}'; then
  printf 'Start unconfirmed. Query profile %s before retrying.\n' "$BROWSER_ID" >&2
  exit 1
fi

# Open runtime.connectUrl while signed in as the profile owner.
# Run the cleanup below when finished; closing the viewer does not stop billing.
curl --fail-with-body -sS --max-time 30 -X POST \
  "https://api.adscrawl.net/cloud-browsers/$BROWSER_ID/stop" \
  -H "x-api-key: $ADSCRAWL_API_KEY"

# HTTP 202 means stopping. Confirm stopped before restarting or deleting.
stopped=false
for ((attempt=0; attempt<60; attempt++)); do
  detail=$(curl --fail-with-body -sS --max-time 30 \
    "https://api.adscrawl.net/cloud-browsers/$BROWSER_ID" \
    -H "x-api-key: $ADSCRAWL_API_KEY") || exit 1
  status=$(printf '%s' "$detail" | jq -er '.runtime.status') || exit 1
  if [ "$status" = "stopped" ]; then
    stopped=true
    break
  fi
  sleep 2
done
if [ "$stopped" != true ]; then
  printf '%s\n' 'Shutdown is not confirmed. Query the same profile before restarting or deleting.' >&2
  exit 1
fi

# The stopped profile remains saved for your next task.
```

超时不能证明浏览器已停止；重试前先查询同一配置。stopping 仍占并发名额。更新会替换提交的 browserSettings 对象或 accounts 列表；删除会永久移除已停止配置。
