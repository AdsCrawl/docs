AdsCrawl uses a credit-based pricing model: every plan comes with a monthly credit allowance (or a one-time grant on Free) that you spend as you use the API. Browser task requests each consume one credit, and Cloud Browsers bill at one credit per started minute. Pick the plan that matches your volume — start on Free to explore the APIs, then move to a paid tier when you need more credits, more saved browser profiles, or more API keys.

## Frequently Asked Questions

<Accordion title="Do credits renew every month?">
  Yes, on all paid plans. Credits reset at the start of each billing cycle — 3,000 on Hobby, 100,000 on Starter, and 500,000 on Pro. The Free plan's 500 credits are a **one-time grant** and do not renew.
</Accordion>

<Accordion title="Can I run a Cloud Browser on the Free plan?">
  You can **save** one Cloud Browser profile on the Free plan, but you need an active paid plan to **launch** it. Concurrent run limits for paid plans are configured on your account. Upgrade to Hobby or above to start running browsers.
</Accordion>

<Accordion title="What counts as one credit?">
  Each browser task request (POST `/html`, POST `/screenshot`, POST `/spa-extract`) consumes **1 credit** when the request passes validation and before execution begins. Cloud Browsers consume **1 credit per started minute**, counted from a successful start until the browser stops. Credits are not refunded if a request fails after consumption has already occurred.
</Accordion>

<Accordion title="How many API keys are included?">
  Each plan includes a different API key allowance:

  | Plan    | API Keys |
  |---------|----------|
  | Free    | 1        |
  | Hobby   | 3        |
  | Starter | 10       |
  | Pro     | 30       |

  Keep your API keys on a trusted server or in a secret manager — never expose them in client-side code, URLs, or logs.
</Accordion>

<Accordion title="Where do I see my plan and remaining credits?">
  Sign in to the [AdsCrawl dashboard](https://app.adscrawl.net/dashboard/) and open **Billing & Usage**. You'll see your current plan, credit balance, and account limits including Cloud Browser profile capacity and concurrent run allowance.
</Accordion>

<Accordion title="What happens if I run out of credits?">
  Once your credit balance reaches zero, API requests return a **402 INSUFFICIENT\_CREDITS** error. Top up your balance or upgrade to a higher plan from the [Billing & Usage](https://app.adscrawl.net/dashboard/) section of the dashboard. Requests are not queued — they fail immediately until credits are available.
</Accordion>
