List your saved cloud browser profiles, newest first. Filters apply together before pagination. All requests require an active account API key in the `x-api-key` header; a dashboard cookie or session JWT alone returns HTTP 401.

## Request

All query parameters are optional.

<ParamField query="page" type="integer" default="1">
  Starts at 1. Missing, invalid, or non-positive values use 1. Capped at 10,000, then at the last matching page.
</ParamField>

<ParamField query="pageSize" type="integer" default="10">
  Missing, invalid, or non-positive values use 10. Values above 100 are capped at 100.
</ParamField>

<ParamField query="remark" type="string">
  Matches a literal substring of the saved remark. Up to 255 characters after trimming whitespace.
</ParamField>

<ParamField query="status" type="string">
  One of starting, running, stopping, or stopped. Omit or pass all for every status. Supply at most once.
</ParamField>

<ParamField query="region" type="string">
  Matches the configured country first, then the observed proxy exit country. Use a country code such as US, custom for a configured proxy with no known country, or unknown when neither country nor proxy is available. Omit or pass all for every region. Supply at most once, with up to 120 characters and no control characters.
</ParamField>

Set `ADSCRAWL_API_KEY` to your account API key. For example, list stopped profiles whose remark contains daily:

<RequestExample>

```bash cURL
curl --get "https://api.adscrawl.net/cloud-browsers" \
  --header "x-api-key: $ADSCRAWL_API_KEY" \
  --data-urlencode "status=stopped" \
  --data-urlencode "remark=daily" \
  --data-urlencode "pageSize=25"
```

</RequestExample>

## Response

| Field | Type | Meaning |
| --- | --- | --- |
| `ok` | boolean | Always true on success. |
| `data` | array | Matching profiles on this page, sorted by creation time descending, then ID descending. |
| `pagination.page` | integer | Page actually returned. |
| `pagination.pageSize` | integer | Effective page capacity; the last page can contain fewer profiles. |
| `pagination.total` | integer | Profiles matching all filters across all pages. |
| `pagination.totalPages` | integer | Matching page count. Empty results return `data: []`, page 1, and one total page. |
| `limit` | integer | Maximum saved profiles for this account. |
| `runningLimit` | integer | Maximum concurrent cloud browser sessions. Zero blocks new starts. |
| `runningCount` | integer | Account-wide saved-profile sessions in starting, running, or stopping state, independent of filters and pagination. |

### Profile fields

| Field | Type | Meaning |
| --- | --- | --- |
| `id` | string (UUID) | Persistent profile ID for detail, start, stop, update, and delete. |
| `remark` | string | Saved label; an unset label is an empty string. |
| `lastOpenedAt` | timestamp or null | Last opening time in UTC; null if never opened. |
| `updatedAt` | timestamp | Last profile update in UTC. |
| `runtime.status` | string | starting, running, stopping, or stopped. Without an active session, runtime contains only `status: "stopped"`. |
| `runtime.sessionId` | string, optional | Active session ID. |
| `runtime.expiresAt` | timestamp, optional | Expiration time when a runtime deadline applies. |
| `runtime.idleExpiresAt` | timestamp, optional | Idle expiration time when an idle policy applies. |
| `runtime.connectUrl` | string, optional | Viewer URL when running and available. Open it while signed in as the profile owner. |

## Errors

| HTTP status | Meaning |
| --- | --- |
| 400 | Invalid filter value, or repeated status or region. Read error for the rejected condition. |
| 401 | An active account API key is required. |
| 500 | The API could not load profiles or account quotas. |

For example, `?status=idle` returns HTTP 400:

```json
{"error":"status must be running, starting, stopping or stopped"}
```

A stopping session still occupies its running slot. Poll [Get Browser](/api-reference/cloud-browsers-get) until stopped before restarting or deleting it.
