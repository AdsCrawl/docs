Send `{}` to start the profile with its saved configuration. Configure the proxy, cookies, and fingerprint on Create or Update. The API uses the key from the request header. If supplied, the optional string `apiKeyId` must match that key’s ID.

<ParamField path="id" type="string" required>
  Saved profile UUID returned by Create or List.
</ParamField>

<ParamField body="apiKeyId" type="string">
  Optional; must match the ID of the authenticated API key when supplied.
</ParamField>

```bash
curl "https://api.adscrawl.net/cloud-browsers/$BROWSER_ID/start" \
  -H "x-api-key: $ADSCRAWL_API_KEY" -H 'Content-Type: application/json' --data '{}'
```

HTTP 200 example:

```json
{
  "ok": true,
  "runtime": {
    "status": "running",
    "sessionId": "6a8a30ad-4788-46cf-a900-a1a1162478b2",
    "connectUrl": "https://app.adscrawl.net/dashboard/cloud-browser-viewer/?cloudBrowserId=7a631d48-afd7-47de-9fcb-8b57e62ccf75&sessionId=6a8a30ad-4788-46cf-a900-a1a1162478b2"
  }
}
```

Open the returned `connectUrl` in a browser signed in as the owner. The runtime can also include `expiresAt` and `idleExpiresAt` when those deadlines apply. If the client disconnects before receiving the response, check Get before retrying. An accepted start can continue after disconnection.

| HTTP status | Meaning |
| --- | --- |
| 400 | Invalid JSON or invalid request fields. An empty body is invalid. |
| 402 | A paid plan or sufficient balance is required. Check `code` for `PAID_PLAN_REQUIRED` or `INSUFFICIENT_CREDITS`. |
| 403 | The supplied `apiKeyId` conflicts with the authenticated key. |
| 404 | Profile unavailable to this account. |
| 409 | Profile already active, session state conflict, or account concurrency exhausted (`CLOUD_BROWSER_CONCURRENCY_LIMIT`). |
| 429 | Session limit for the API key or user reached. |
| 503 | Runtime unavailable or service capacity exhausted. |

## Authentication

All requests use `https://api.adscrawl.net` and require an active account API key in `x-api-key`. A dashboard cookie or session JWT alone returns HTTP 401. Set `ADSCRAWL_API_KEY` before running the examples. For one profile, set `BROWSER_ID` to its saved UUID.
